HTTP Methods

RESTful Design Principles

# Resources as nouns, not verbs
# GOOD
GET    /users          # List users
GET    /users/{id}     # Get user
POST   /users          # Create user
PUT    /users/{id}     # Update user
DELETE /users/{id}     # Delete user

# BAD
GET    /get_users
POST   /create_user
POST   /delete_user
